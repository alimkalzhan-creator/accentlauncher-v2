# Accent Launcher — лаунчер для Android-магнитолы

Рабочий стол в стиле sci‑fi с чёрным Hyundai Accent 2015 (рестайлинг).

## Что умеет
- Погода по GPS: температура, город, ветер, влажность, УФ, давление (open-meteo, без ключа).
- Музыка: название трека, исполнитель, обложка, кнопки ⏮ ⏯ ⏭ для любого плеера (нужно один раз дать «Доступ к уведомлениям»).
- Скорость и компас по GPS, высота, график скорости.
- Календарь на месяц, часы, дата.
- Меню всех приложений, нижняя панель из 8 кнопок (долгое нажатие — выбрать своё приложение).
- Настройки внутри лаунчера (значок ⚙ справа сверху или аватар слева):
  - 8 цветовых тем + свой цвет ползунками;
  - замена виджета в каждом из трёх блоков: Музыка, Погода, Скорость/компас, Календарь, Часы, Ярлыки (6 приложений);
  - своё фото машины вместо рисунка (PNG без фона выглядит лучше всего), подпись под машиной;
  - кнопка «Сделать лаунчером по умолчанию».

## Как получить APK (без компьютера с Android Studio)
1. Создайте пустой репозиторий на github.com и загрузите в него содержимое этой папки (Add file → Upload files).
2. Откройте вкладку **Actions** — сборка «Build APK» запустится сама (≈5 минут).
3. Откройте завершённую сборку → внизу **Artifacts → AccentLauncher-apk** → скачайте, внутри `app-release.apk`.

Или в Android Studio: File → Open → эта папка → Build → Build APK(s).

## Установка на магнитолу
1. Скопируйте APK на флешку, откройте файловым менеджером на магнитоле, разрешите установку из неизвестных источников.
2. Нажмите «Домой» → выберите **Accent Launcher** → «Всегда».
   На некоторых китайских магнитолах лаунчер выбирается в Настройки → Приложения → Приложения по умолчанию → Главный экран (или в заводском меню).
3. Разрешите доступ к местоположению, затем в настройках лаунчера нажмите «Разрешить доступ к музыке».
